# 书稿分批与局部更新

## 使用方式

- 「更新书稿」参考已有小节概况归类新增素材，只生成新增或内容变化的小节。没有变化时不调用模型。
- 「整理全书」是显式的完整重整：依据全部有效原话重新分批归类和生成，旧稿保存为历史版本。适合准备导出前使用，耗时和调用次数通常更多。它不保证自动消除所有跨章节矛盾，仍需本人审阅。
- 任务显示素材归类和小节完成进度；已完成小节可预览。失败或本地服务重启后，点击「继续生成」。
- 正式书稿在全部批次通过检查后统一更新。逐小节检查点单独保存，不会把半份结果直接覆盖原稿。
- 当前选择的模型保持不变；千问文字模型菜单显示 qwen3.8-flash、qwen3.7-plus、qwen3.8-max，选择后自动保存。

## 长度与来源

原始聊天和有效回忆保留在书籍文件中。长素材按句子和段落拆分；单句过长时按 Unicode 字符继续拆分，既不丢字，也不把字符切坏。

每个片段有稳定的素材 ID、原话 ID、片段序号及内容摘要值。一次规划请求使用少量素材和分页的小节目录；一次写作只使用相关原话。概况用于定位，不作为写作事实来源。旧稿初次迁移按照出处关联到小节，并重新整理相关原话；原稿进入历史版本。

当前使用保守的 UTF-8 字节预算来限制请求，**不是精确 tokenizer 计数**：完整 messages 加封装余量不得超过 14,000 的保守输入预算，另预留 4,000 输出 token。原话片段最多 2,000 字节，正常小节素材分组约 5,500 字节。适用于当前提供的长上下文模型。服务商明确报告长度超限，或返回输出截断时，任务会继续缩小批次；不能无限重试，仍无法完成时保留进度并提示继续。

不再给整本生成结果设置 8,000 token 或 30 章的总上限。每个小节单独请求、检查和保存。

所有输入片段必须被归类一次；生成正文必须引用每个片段，并且不能引用未知 ID。覆盖检查验证的是素材片段与出处对应，不证明每条事实都完整保留或叙述正确。模型报告的疑点显示在「待核对的问题」。无法判断主题的素材仍保留在「待归类」章节。

## 更新和恢复

小节内容摘要值变化才需要重新写作。增补原话会先与目录概况匹配，关联到旧小节或创建新小节。大节进一步拆成有顺序的小节，未变化的小节保留正文和 ID。

每完成归类批次或写作小节，保存 `manuscript-progress/<bookId>.json`。恢复前核对素材、现有正文、模型、地区及任务模式。若这些条件变化，不直接复用不兼容的检查点。仅增加新故事而未修改旧素材时，正在进行的任务可完成原快照，新故事下次更新。

生成期间修改、删除原话，或改动原稿，会阻止旧结果发布。已有索引的书稿如果检测到人工修改，停止自动覆盖并保留原稿。历史版本连同小节索引一并保存和恢复。删除整本书也删除它的生成检查点。

## 仍需注意

大型书籍首次整理和主动全书重整仍可能需要较长时间；当前按小节顺序执行，便于恢复并控制请求量。这里没有承诺固定完成时间。目录很大时会分页读取，分类请求数量会增加。

当前不提供自动解决事实矛盾的承诺，也不自动覆盖检测到的人工润色。首次处理旧版书稿没有历史生成指纹可供比较，因此通过保存旧稿版本保护已有文字。费用以实际服务商账单为准，任务记录本轮接口返回的 token 用量。

## 正文与待确认素材

正文使用第一人称，出处编号保存在独立字段，不出现在段落里。不明确的原话保留在“待确认的原话”，不会凑成章节或进入导出稿。修正原话后可以重新分类。含糊的时间、地点和用词仍需本人核对；模型不得擅自翻译人名或补足事实。

## 千问统一连接

设置页只需一个千问 API Key，文字和实时语音使用千问 AI 平台统一入口，无需地区或 Workspace ID。旧的地区配置保留作兼容；当前设置使用统一密钥。文字入口为 `https://maas.qianwenaiapi.com/compatible-mode/v1/chat/completions`，实时语音为 `wss://maas.qianwenaiapi.com/api-ws/v1/realtime`。更换密钥后点击“保存设置”。
